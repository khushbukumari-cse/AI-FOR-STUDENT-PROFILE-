# STUDYQUEST - AI ASSISTANT FOR STUDENTS
A FREE,MOBILE-FRIENDLY STUDENT TRACKER WITH AN ANIME-INSPIERD DARK INTERFACE
## FEATURE 
- SUTUDENT PROFILE WITH SCHOOLOR COLLAGE NAME,SUBJECTS AND PHOTO
- DAILY LOG:ATTANDANCE PER SUBJECT,REASON FOR MISSED CLASSES,MOOD,STRESS,SLEEP AND STUDY HOURS
- TEST RESULTS WITH SUBJECT-WISE PERCENTAGE AND GRADES
- TO-DO LIST (QUESTS) WITH XP,LEVELS,STREKS AND BADGES
- AI PLANNER THAT SUGGESTS TASKS FOR TOMMOROW,THIS WEEK OR THIS MONTH
- ALARMS AND QUEST REMINDERS
- DAY,WEEK,MONTH AND YEAR PERFORMANCE ANALYSIS
- BACKUP AND RESTORE OF YOUR DATA
